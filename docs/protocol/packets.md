# Complete packet catalogue

[Overview](README.md) · [Implemented wire formats](wire-formats.md) · [Source-only layouts and gaps](upstream-packets.md)

Every row is one member of the pinned `PacketType : byte` enum, in numeric order. **113 entries, IDs 0–112**. Authentication precedes this opcode namespace. “Pinned direction” is established from server handler registration plus generated **and legacy** client routing; the `ServerOnlyPacket` attribute alone is not sufficient. It establishes source presence, not live-server support.

“Companion” names the currently implemented direction, which may consume only a prefix or implement only some subtypes. `—` means no Companion codec. **C→S** is a client request, **S→C** is a server observation. Upstream links marked **client** point to receivers; **server** links point to request handlers. S→C writers are in the pinned [CommandBuilder](https://github.com/Doddler/RagnarokRebuildTcp/blob/4099e2c000c3c550516760b9c1241595aac9aceb/RoRebuildServer/RoRebuildServer/Networking/CommandBuilder.cs) and session initialization. Registered no-op/fallback/legacy entries are qualified in the notes.

## Coverage limits

- Names and directions remain on the fixed [PacketType source](https://github.com/Doddler/RagnarokRebuildTcp/blob/4099e2c000c3c550516760b9c1241595aac9aceb/RoRebuildServer/RebuildSharedData/Networking/PacketType.cs). The server uses reflected handler registration, including inherited admin attributes. The client first checks its generated valid-handler table, then its legacy switch. A generated `InvalidPacket` entry by itself is not evidence that no handler exists.
- Companion consumes a subset of some packets: core prefix handling, ignored animation fields, partial NPC subtypes, byte-array masks, and explicit deployed party exceptions are detailed in [wire formats](wire-formats.md). Decode coverage is separate from controller feature support.
- Privileged/admin/debug entries are inventoried for completeness. They are outside the ordinary-player feature surface. Database travel uses the existing constrained 64 path, not arbitrary admin commands. Appearance 68 and random movement 21 have source-specific gates rather than a uniform admin attribute.
- Guild/friends/clan, private whispers, mail, bank, auction, direct player trade and repair have no implemented Companion contract here. Their absence from this pinned enum does not prove absence from the live service. Obtain matching source or deployed evidence before assigning an opcode or implementing them.
