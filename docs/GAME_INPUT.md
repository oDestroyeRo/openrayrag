# Game input ownership

Opening inventory, skills, equipment or another local game panel briefly yields new bot decisions. Trusted pointer and keyboard input extends the grace period to two seconds after the latest event. The current action remains owned: incoming confirmations, skill motion, cooldowns, accepted movement and finite run allowances continue. Repeated input does not look like Mac sleep, replenish the run budget, or retry a resource action. Real timeout, health, connection and session-limit failures keep their existing safeguards.

The official socket's outgoing binary opcode separates local input from gameplay. Movement, attack, skill, item, equipment, NPC, container, party and vending commands retain the existing conservative manual takeover. The allowlist is pinned to Rebuild `4099e2c000c3c550516760b9c1241595aac9aceb`; unknown opcodes do not acquire authority. Only the current verified game socket with its own observed ready actor is classified. The raw login handshake has no opcode framing and is never inspected, including after reconnect. Character entry, readiness, Ping, chat, emotes, facing and text queries are excluded; strings and Blobs are not inspected. The observer reads only the first byte, never stores or logs packet bodies, and forwards each original official send once. Companion's own transports call the native socket prototype and bypass the hook.

Every trusted official input still retires unsent memo/socket previews. It also taints a sent socket operation, which needs a fresh full inventory readback to reconcile without attributing the old result. A sent memo keeps its full-readback fence. Explicit Companion Stop cancels run intent; it does not undo a transmitted action. Real manual gameplay can leave an interrupted cast or economic operation uncertain rather than fabricate success or repeat it.

Source evidence: the pinned `RebuildClient/Assets/Scripts/PlayerControl/CameraFollower.cs` toggles skills at line 2035, equipment at 2048 and inventory at 2052 locally. Space calls StopPlayer at line 2001. `RebuildClient/Assets/Scripts/Network/NetworkManager.cs` writes the PacketType opcode first and sends the exact byte buffer (lines 478–506); `RoRebuildServer/RebuildSharedData/Networking/PacketType.cs` defines the allowlist IDs. This establishes the source contract, not deployed input or network proof.

Synthetic controller and bridge tests cover the normal late Fire Bolt opener result, own actor zero, panel input during normal Thief attack, pickup, explicit accepted movement, recovery-item and automatic ammo receipts, real unconfirmed-item timeout, repeated input longer than five seconds, retained session limits and actual manual takeover. The bridge tests exercise the installed listeners and socket override, auth/query exclusions, active/build gates, native-prototype bypass and hook failure without a repeated official send. No live input, account action or native app launch is performed by these tests. Live panel-resume verification remains separate.
